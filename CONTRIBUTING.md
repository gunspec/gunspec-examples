# Contributing

This repository is a read-only copy of the examples that ship with the GunSpec SDKs. It is rewritten from the GunSpec monorepo on every stable SDK release, so a commit made here directly would be overwritten.

- **An example is broken or unclear?** Open an issue here.
- **Want an example that is not here?** Open an issue describing what you are building.
- **Have a fix?** A pull request is welcome. It is read, applied upstream by hand, and reaches this repository with the next release. The pull request itself is then closed.
